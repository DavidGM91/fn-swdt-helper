# fn-swdt-helper
A little helper page to help you manage your tycoon on the Fortnite game Star Wars Drone Tycoon.

# Why this project
This project was my way of testing agentic coding, for it I tried a lot of different models, both cloud and local on 16GBVram. 
While the project it's not 100% AI for I had to intervene in many situations and even make some snippets by hand that the AI just couldn't do right.
The architure of the data was also handpicked by me to guide the AI into the features the app needed.
I did learn a lot of how to properly prompt an agent, their capabilities and limitations.
