== Droid and Credit Requirements ==

Down here is a list of all droid and credit rebirth requirements for all 5 paths. Next to each droid you will notice a number. This number means that the droid is later required for another rebirth requirement.

* ¹ = {{Variant|Gold}} variant is required for a later rebirth.
* ² = {{Variant|Diamond}} variant is required for a later rebirth.
* ³ = {{Variant|Rainbow}} variant is required for a later rebirth.
* ⁴ = {{Variant|Beskar}} variant is required for a later rebirth.
* ⁵ = {{Variant|Galactic}} variant is required for a later rebirth.
* ⁶ = {{Variant|Stellar}} variant is required for a later rebirth.
* ⁷ = Any {{Variant|Kyber}} variant is required for a later rebirth.
* ⁻ = Same variant is required for a later rebirth.
